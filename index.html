OKTO DRONE MAPPER PRO • PRIVACY POLICY

Kebijakan Privasi / Privacy Policy

Package ID: com.oktodrone.mapper • Version: V.9.3 • Effective Date: November 23, 2026

1. Ringkasan Data & Privasi / Data Collection Summary

Bahasa Indonesia

Okto Drone Mapper Pro beroperasi dengan prinsip local-first. Rencana penerbangan pemetaan (waypoint, poligon AOI, parameter kamera, DEM GeoTIFF, foto geotag, sensor perangkat, maupun file GPX/KML/KMZ/SRT/MP4) diproses dan disimpan langsung di perangkat Anda.

Pengembang tidak mengoperasikan server pelacak pribadi dan tidak menjual data pribadi Anda. Aplikasi menampilkan iklan Google AdMob (Banner Bawah, Native Advanced, serta Rewarded Video opsional) sesuai persetujuan Google UMP, dengan pengaman 0 iklan selama penerbangan drone berlangsung.

English

Okto Drone Mapper Pro is designed on a local-first architecture. Photogrammetry flight plans, geotagged photos, device sensor readings, and GPX/KML/KMZ/SRT/MP4 files are computed and stored locally on your device.

The developer does not operate proprietary tracking servers and does not sell your personal data. The app integrates Google AdMob ads (Anchored Banner, Native Advanced, and opt-in Rewarded Video) managed via Google UMP consent, with strict zero-ads suppression throughout all flight-critical drone phases.

2. Izin Perangkat & Tujuan Penggunaan / Device Permissions & Purpose

Bahasa Indonesia
  • Lokasi Presisi & Perkiraan (ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION): Digunakan hanya saat aplikasi dibuka untuk menampilkan posisi real-time di peta, Home Point, trek GPS, geotagging foto, serta alat ukur lapangan.
  • Kamera (CAMERA): Opsional, digunakan saat mengambil foto GeoTag, foto dokumentasi proyek, maupun pemotretan patok BPN secara lokal.
  • Bluetooth & Aksesori USB: Digunakan semata-mata untuk mendeteksi dan berkomunikasi dengan remote controller / pesawat DJI yang didukung.
  • Akses File Terpilih Pengguna (SAF / MediaStore): Aplikasi hanya membaca atau menulis file/folder/foto yang secara eksplisit Anda pilih.
  • Sensor & Hardware Lokal: Kompas, barometer, sensor cahaya, akselerometer, senter LED (torch), peluit darurat & getar dijalankan secara lokal di perangkat tanpa mengirim data ke server pengembang.
  • Advertising ID (AD_ID): Digunakan oleh Google AdMob & Google UMP Consent SDK sesuai pilihan persetujuan pengguna (iklan non-personalisasi tersedia di wilayah EEA/UK/CH).
English
  • Precise & Approximate Location (ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION): Used only while using the app to render live GPS position on the map, establish Home Point reference, geotag photos, record field tracks, and run geodesy tools.
  • Camera (CAMERA): Optional, used when capturing GeoTag photos, project documentation, or BPN boundary stake certificates locally.
  • Bluetooth & USB Accessory: Used exclusively to pair and communicate with compatible DJI remote controllers and aircraft.
  • User-Selected File Access (SAF / MediaStore): The app accesses only the files, photos, and export folders you explicitly select.
  • Local Device Hardware & Sensors: Compass, barometer, ambient light, accelerometer, LED torch, emergency acoustic tone, and haptics run strictly on-device.
  • Advertising ID (AD_ID): Used by Google AdMob & Google UMP Consent SDK in accordance with user consent choices (non-personalized ads supported in EEA/UK/CH).

3. Layanan Pihak Ketiga / Third-Party SDKs & Map Providers

Bahasa Indonesia
  • Google AdMob & UMP Consent SDK (com.google.android.gms.ads, com.google.android.ump): Menampilkan iklan Banner Bawah, Native Advanced, dan Rewarded Video opsional. Seluruh iklan otomatis dinonaktifkan (0 iklan) saat drone menyalakan motor, sedang terbang, mendarat, Return-To-Home, atau selama mode FPV / kokpit SDK aktif.
  • DJI Mobile SDK (com.dji): Mengelola koneksi hardware drone dan aktivasi lisensi App Key ke server DJI saat registrasi SDK.
  • Server Peta & Geocoding: Saat peta online atau unduhan tile dipakai, koordinat tile diminta via HTTPS dari penyedia peta terpilih (OpenStreetMap, Esri, OpenTopoMap, Google Tiles, Nominatim).
English
  • Google AdMob & UMP Consent SDK (com.google.android.gms.ads, com.google.android.ump): Serves Anchored Banner, Native Advanced, and opt-in Rewarded Video advertisements. All ads are strictly suppressed (0 ads) whenever drone motors are armed, aircraft is airborne, landing, returning home, or inside active FPV / SDK flight screens.
  • DJI Mobile SDK (com.dji): Manages hardware communication and SDK App Key registration directly with DJI servers.
  • Map Tile & Search Providers: Online map viewing requests map tiles and geocoding queries over HTTPS from the selected map provider.

4. Penyimpanan Lokal, Penghapusan Data & Kontak

Semua data tersimpan di penyimpanan internal aplikasi dan dapat dihapus permanen kapan saja melalui Android App Info > Clear Storage atau mencopot aplikasi.
